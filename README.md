# VYBE TV downloads

Official download page for **VYBE TV** for Amazon Fire TV / Firestick.

VYBE TV is a media player. It doesn't include channels, movies or an IPTV subscription: you use
the service you're already authorized to use. VYBE TV is free during Early Access; future
commercial terms may change, with advance notice.

## Install on Firestick

1. Install the free **Downloader** app from the Fire TV home screen (search "Downloader").
2. Allow it to install apps: Settings > My Fire TV > Developer options > Install unknown apps > Downloader: ON.
3. In Downloader, enter the VYBE TV code (or the link below), then choose **Install** and **Open**.

Latest version: see [Releases](../../releases/latest).

Every release lists the SHA-256 checksum of its APK. The APK is signed with the VYBE TV
production certificate (SHA-256 `018df6c6a347674b0daae5d69e5f18d8b12c144e46f7df6f0637f4cd0459501b`).

This repository only contains release files. It has no source code.
